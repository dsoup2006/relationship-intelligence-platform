# Explorer 3.0 Specification

## Purpose

The Explorer is the primary navigation system for Nexus.

It allows users to navigate entities, collections, favorites,
and intelligent views without interacting directly with the graph.

## Milestone 1

- Search box
- Expandable entity categories
- Live counts
- Entity list
- Click to select an entity

## Category Behavior

Each entity category displays:

- Icon
- Label
- Live count
- Expand or collapse control
- Matching entities underneath when expanded

## Entity Selection

Clicking an entity should:

- Select the entity
- Switch to Graph view
- Open the entity in the Inspector

## Search

Search should filter entities by:

- Name
- Type
- Tags
- City
- Address
- Description

## Design Goals

The Explorer should feel:

- Clean
- Compact
- Fast
- Similar to Apple Finder
- Easy to use with large projects
